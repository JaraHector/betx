APUESTAS V1.6 — INSTALACIÓN EN IPHONE Y USO SIN INTERNET

OPCIÓN RECOMENDADA (PWA, requiere conexión una sola vez):
1. Publicar los archivos de esta carpeta en un sitio HTTPS (por ejemplo GitHub Pages).
2. En el iPhone, abrir la URL HTTPS en Safari.
3. Tocar Compartir > Agregar a pantalla de inicio > Agregar.
4. Abrir Apuestas desde el icono. Esperar unos segundos para que se guarde el contenido.
5. Activar modo avión y abrirla de nuevo para comprobar que funciona.
6. No borrar los datos del sitio Safari, porque se perderían los cambios locales.

OPCIÓN RÁPIDA (sin publicar):
1. Guardar apuestas_offline.html en Archivos del iPhone antes del vuelo.
2. Abrirlo desde Archivos, usando Safari si el sistema lo permite.
3. Esta vía depende de iOS y puede fallar en algunas versiones; no garantiza almacenamiento persistente ni instalación en Inicio.

La instalación PWA NO se consigue simplemente abriendo un ZIP.
GitHub Pages: crear repositorio, subir los archivos del ZIP a la raíz y activar Settings > Pages > Deploy from a branch > main / root. Una vez publicada la URL HTTPS, seguir la opción recomendada.
